# Bstress — TG-BUCKET upload stress tester

Streams generated bytes directly to TG-BUCKET without creating the test file on disk.

## Upload protocol

Bstress uses the TG-BUCKET API exposed by the test UI:

`PUT /files/:key`

Headers:

- `Content-Type: application/octet-stream`
- `Authorization: Bearer <API_KEY>` when `API_KEY` is configured

The request body is streamed from a generator.

## Important

Set `FILE_SIZE_BYTES` below TG-BUCKET's maximum object size. A request larger than the bucket's per-object limit will be rejected even though the service is reachable.

## Render

Build command:

`pip install -r requirements.txt`

Start command:

`gunicorn app:app`

Required environment variables:

- `BUCKET_URL`
- `API_KEY`

Optional:

- `FILE_SIZE_BYTES`
- `TG_BOT_TOKEN`
- `TG_CHAT_ID`

## Stats

`GET /` returns live status. `GET /stats` returns detailed counters.

Only HTTP 2xx responses are counted as completed uploads and added to total uploaded bytes. Failed responses include a short response-body preview for debugging.
